# CHANGELOG

## 1.0.1

- 修复：按前缀扫描 `pair/` / `next/` 时，更长的首词（如「你们」之于「你」）
  也会命中；现在要求分隔符 `\x1f` 紧跟在前缀之后，不再把半截词连同分隔符
  当成候选（联想栏出现「个␟5」这类乱码）。读取时同时跳过含控制字符的旧
  键，已经写坏的条目也不再显示。

## 1.0.0

- 新增：追加式学习日志、计数衰减、近期选择 MRU、退格撤销、连续造词、用户二元组。
- 新增：按当前码串回放学过的词（`candidates`，注释「自造」），与上游候选合并去重。
- 新增：按最近提交词产出二元组后继（`next`），供 `pime-predict-context` 使用。
