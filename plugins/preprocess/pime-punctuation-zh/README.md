# pime-punctuation-zh

`preprocess`（Lua）：把半角标点在提交前替换为中文全角标点。

## 行为

- 仅处理 `event.type = text` / `key`，且无修饰键。
- keymap 已识别为 `space / enter / escape / backspace / tab / delete` 时放行。
- 命中映射表后输出一条 `commit` 命令，`handled = true`。

| 输入 | 输出 |
|---|---|
| `,` `.` `?` `!` `:` `;` | `，` `。` `？` `！` `：` `；` |
| `(` `)` `[` `]` `{` `}` | `（` `）` `【` `】` `｛` `｝` |
| `\` `~` `@` `#` `$` `%` `^` `&` `*` | `、` `～` `＠` `＃` `￥` `％` `＾` `＆` `＊` |
| `-` `_` `+` `=` `\|` `/` `` ` `` | `－` `＿` `＋` `＝` `｜` `／` `｀` |
| `<` `>` | `《` `》` |
| `"` `'`（`quotes=chinese`） | 交替 `“` `”` / `‘` `’` |
| `"` `'`（`quotes=straight`） | 原样放行 |

## Settings

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | true | 关闭后完全放行 |
| `quotes` | enum | `chinese` | `chinese` 转中文引号并交替开合；`straight` 保持原样 |

## State

| 键 | 类型 | 说明 |
|---|---|---|
| `quote_open` | bool | 下一个中文引号是开引号 |

## 已知边界

省略号（`...`）、破折号（`--`）与“自动补全括号并把光标放到中间”都需要编辑器
光标控制；pime 命令 ABI 只有 `commit` / `set_composition`，没有移动光标命令，
因此本插件不做近似插入，只做逐字符全角转换。

## 用例

`tests/cases/`：逗号、花括号、符号、引号交替、空格放行、关引号样式。
