# Changelog

## 1.0.0

- 首个版本：两键成音节、零声母处理、consumed/syllable workspace 契约。

## 1.1.0

- 支持四套双拼：小鹤、自然码、微软、搜狗，`scheme` 设置切换。
- 零声母规则按方案区分：小鹤/自然码用双击/原样/首字母+韵母键；微软/搜狗用
  `o` + 韵母键，并接受 `a/e` 首字母与 `ou` 原样。
- 微软/搜狗支持 `;` 键输入 `ing`；`j/q/x/y` 后的 `ü` 同时接受 `u`/`v` 键。
- 单键后按空格/回车/选词时把半码作为一个前缀音节提交，不再丢失。
- 移除未实现的 `show_half_code` 设置。
