# Changelog

## 1.1.0

- 用户学习：选词事件写入 `pick/<raw>` 与 `last/<text>`，下次同一读音优先。
- 近期选择：7 天内用过的候选按剩余时间衰减加分。
- 退格撤销：选词后 5 秒内退格删除学习记录（state 记录上一次选择）。
- 领域偏置：`profile` 选择聊天/代码/正式词表，命中候选注释“领域”。
- 长词内聚：`words == 1` 且 3 字以上的整词加分。
- 候选注释：`comment` 输出“常用/最近/领域”，供 format 显示。
- 新增 `store.kv`、`time` 能力；`state_schema`/`store_schema` 升到 2。
- 测试运行器与模拟器支持多帧批量调用，覆盖跨调用的学习/撤销。

## 1.0.0

- 首个版本：短词加权 + 分数降序重排。
