# Changelog

## 1.0.5

- 中文链里英文要“够格”才排到中文前面：原码本身就是词表里的词，或补全里
  有 freq ≥ 50 的常用词。像 `tij` 只命中 `Tijuana`（freq 7）这种冷僻专名时，
  原码和补全退到中文候选之后，空格仍然提交中文。

## 1.0.4

- 中文链的英文混入加长度阈值：原码至少 3 个字母才给英文候选。`go`、`ok`
  这类两字母输入既可能是简拼也可能是短英文词，此前会被 `good`/`okay` 抢先；
  现在保持中文视图，`goo`、`hel`、`dont` 起才混入。

## 1.0.3

- 中文链不再输出拼写建议：`nih`、`zhongg` 这类“完整音节 + 下一个音节的声母”
  在英文词表里没有前缀命中，此前会被当作错拼给出 `big`/`air`/`ah` 等候选，
  挡在中文候选前面。现在混输只做前缀补全，英文侧没有实际新增时保持中文视图。

## 1.0.2

- 中英混输：挂在拼音链时读 `pinyin-parse/raw`，对“不像完整拼音”的输入
  （`goo`、`hel`、`dont`）输出合并视图：原码与两条补全在前、中文候选在中、
  其余英文补全在后；纯拼音（`ni`、`nihao`）不混入。
- 没有英文新增时输出空数组，中文候选不被遮挡；去掉 `requires`
  （中文链不需要 english-parse）。

## 1.0.1

- 补齐候选前先收集再排序：此前按词表顺序截断，`hel` 会漏掉 `hello`。
- 大词表（3.6 万条）随包发布，来源与过滤规则见 `data/english/README.md`。

## 1.0.0

- 首个版本：原码优先、前缀补全、拼写建议、按输入大小写回写。
